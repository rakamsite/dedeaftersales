# STS Log & Guide Starter

این پوشه یک **استارت‌پک آماده** برای پروژه‌های وردپرسی است که فقط شامل دو بخش زیر در پنل ادمین است:

1. صفحه **بروزرسانی‌ها**
2. صفحه **راهنما**

## ساختار

- `sts-log-guide-starter.php`: فایل اصلی افزونه.
- `includes/admin-log-guide.php`: منطق کامل ثبت زیرمنوها، قوانین ثبت لاگ و رندر دو صفحه.

## نصب سریع در هر پروژه

1. پوشه `sts-log-guide-starter` را داخل مسیر `wp-content/plugins` کپی کنید.
2. از پنل وردپرس افزونه **STS Log & Guide Starter** را فعال کنید.
3. اگر CPT شما `ticket` نیست، اسلاگ منوی والد را با فیلتر زیر تغییر دهید:

```php
add_filter('stslg_parent_menu_slug', function () {
    return 'edit.php?post_type=your_cpt';
});
```

## قوانین ثبت بروزرسانی (Built-in)

قوانین ثبت لاگ به‌صورت پیش‌فرض در تابع `stslg_get_update_log_rules()` قرار گرفته‌اند و در خود صفحه بروزرسانی نمایش داده می‌شوند تا نیاز به تعریف مجدد در هر ریپازیتوری نباشد.

## توسعه سریع

- برای افزودن نسخه جدید فقط تابع `stslg_get_updates_log_entries()` را آپدیت کنید.
- بخش راهنما فعلاً طبق نیاز شما خالی است و فقط تیترها را نمایش می‌دهد.
